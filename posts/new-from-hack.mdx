Clojure社区是Clojure 是一种运行在 Java 虚拟机（JVM）上的现代 Lisp 方言，它结合了 Lisp 强大的宏系统和函数式编程特性，同时也是一门动态、通用的编程语言。Clojure 社区是一个活跃的开发者和爱好者群体，他们共同支持和推动 Clojure 语言的发展。

Clojure 是一种编程语言，它属于 Lisp 语言家族，是一种现代的方言。Lisp 语言以其宏系统、代码即数据（code-as-data）的哲学和递归函数而闻名。Clojure 保留了这些特性，并且添加了一些现代编程语言的特性，如函数式编程支持和不可变数据结构。

Clojure 运行在 Java 虚拟机（JVM）上，这意味着 Clojure 代码会被编译成 Java 字节码，然后在 JVM 上执行。
