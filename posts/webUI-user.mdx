## 安装WebUI
github 项目官方地址：(https://github.com/AUTOMATIC1111/stable-diffusion-webui)
卸载高版本的python，安装指定的python 3.10.6，[下载地址](https://www.python.org/downloads/release/python-3106/)
下载代码：
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
从 Windows 资源管理器运行 webui-user.bat。

1、提示Torch is not able to use GPU; add --skip-torch-cuda-test to COMMANDLINE_ARGS variable to disable this check
解决：a、直接在webui-user.bat脚本中修改配置，set COMMANDLINE_ARGS=--skip-torch-cuda-test
b、或者修改项目启动文件跳过检查，modules/launch_utils.py，屏蔽 #raise RuntimeError(
        #    'Torch is not able to use GPU; '
        #    'add --skip-torch-cuda-test to COMMANDLINE_ARGS variable to disable this check'
        #)
2、提示Cloning assets into D:\git_home\agentic-workflow\stable-diffusion-webui\repositories\stable-diffusion-webui-assets...
Cloning into 'D:\git_home\agentic-workflow\stable-diffusion-webui\repositories\stable-diffusion-webui-assets'...

解决： 手动克隆仓库 git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui-assets.git D:/git_home/agentic-workflow/stable-diffusion-webui/repositories/stable-diffusion-webui-assets


3、继续执行在dos环境下执行
./webui-user.bat，指定当前目录
启动成功有开启web页面，进入新天地。

4、后台错误日志分析
启动 Stable Diffusion Web UI 时遇到了一些问题。让我们逐个分析这些错误，并提供相应的解决方案：
未找到 xformers 模块

没有找到 NVIDIA GPU 驱动

未找到模型文件
你需要下载一个模型文件，通常是 .ckpt 或 .safetensors 文件，并将其放置在以下位置之一：
D:\git_home\agentic-workflow\stable-diffusion-webui\model.ckpt
或者放置在 D:\git_home\agentic-workflow\stable-diffusion-webui\models\Stable-diffusion\ 目录下
你可以从 Hugging Face 网站下载合适的模型文件。例如，Stable Diffusion v1.5 的模型文件。
https://huggingface.co/CompVis/stable-diffusion-v1-4
下载完成后，将文件放到上述目录中，再次启动 Web UI。

Torch Half 精度问题
添加参数类型，set COMMANDLINE_ARGS=--skip-torch-cuda-test --no-half --use-cpu all

在 stable-diffusion-webui\models 目录中，每个文件夹通常代表一个特定的模型或与模型相关的组件。
Codeformer:

这是一个用于图像超分辨率的模型，可以将低分辨率的图像增强为高分辨率的图像，同时保持图像的自然质感和细节。
deepbooru:

这可能是指一个用于图像识别或分类的深度学习模型，可能用于识别图像中的特定内容或特征。
GFPGAN:

GFPGAN（Generative Facial Privacy Protection Adversarial Network）是一个用于人脸隐私保护的生成对抗网络，它可以在保护人脸隐私的同时生成逼真的人脸图像。
hypernetworks:

超网络（Hypernetworks）是一种特殊的神经网络，可以用来动态生成其他神经网络的权重。这种方法可以用于各种任务，如图像生成、风格迁移等。
karlo:

这可能是一个特定模型的名称或一个特定功能的实现，但需要更多上下文来确定其确切用途。
Lora:

LoRA（Low-Rank Adaptation）是一种模型微调技术，它通过引入低秩结构来调整预训练模型的权重，以适应新的任务。
Stable-diffusion:

这是 Stability AI 开发的文本到图像生成模型，可以根据文本描述生成高质量的图像。
VAE:

VAE（变分自编码器）是一种生成模型，用于学习数据的压缩表示。它由两部分组成：编码器和解码器。编码器将数据映射到一个潜在空间，解码器从潜在空间重建数据。

## 不同点
功能定位:

Dify: 更加注重于提供一个全面的工具集，支持多种功能如Web搜索、科学计算和图像生成。它旨在通过工具的组合来增强AI应用的能力，适合需要执行复杂任务的用户。

WebUI: 主要专注于图像生成，提供丰富的设置和选项，适合对图像生成过程有深入控制需求的用户。它的功能更倾向于细致的图像合成和艺术创作。

## 步骤和实施经验

安装WebUI: 按照官方文档的说明安装和运行WebUI。

启用自动化脚本: 在启动WebUI时添加--allow-code参数,开启自定义脚本功能。

编写自动化脚本: 在WebUI的"Scripts"选项卡下的"Custom script"输入框中编写Python代码,实现自动化任务。

访问WebUI参数: 在脚本中使用p变量获取WebUI的输入参数,如提示词、种子等。

执行自动化操作: 利用Python库如Selenium等,编写代码模拟用户操作Web页面,完成自动化任务。

输出结果: 使用display(images, seed, info)函数将生成的图像、种子和信息输出到WebUI。


>总的来说，如果你的兴趣在于前端和浏览器自动化，那么从WebUI开始学习；如果你对构建AI应用更感兴趣，那么DIFY会是一个不错的选择。
