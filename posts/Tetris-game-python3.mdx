这种做法会导致界面上会被强制中断，等待用户输入，不符需求。
实际的需求是界面一直刷新，同时判断用户是否操作输入。
一般这种解法方法是采用多线程的方式，也就是主程序执行图像不停的刷新，另一个线程执行接收用户请求输入。

```python
import threading

# 全局变量用于捕获用户输入
user_input = None
def get_input():
    global user_input
    while True:
        user_input = input()
# 启动线程处理用户输入
input_thread = threading.Thread(target=get_input)
input_thread.daemon = True  # 守护线程
input_thread.start()
```
