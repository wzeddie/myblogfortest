## 安装DIfy WebUI
git clone 项目地址
安装 Docker 和
 Docker Compose：
启动 Dify 服务器的最简单方法是运行我们的 docker-compose.yml 文件。在运行安装命令之前，请确保您的机器上安装了 Docker 和 Docker Compose：
cd docker，到D:\git_home\agentic-workflow\dify\docker>
先启动docker，否则无法启动
cp .env.example .env
docker compose up -d
运行后，可以在浏览器上访问 http://localhost/install 进入 Dify 控制台并开始初始化安装操作。
